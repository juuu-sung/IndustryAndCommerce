확인할 사항과 한계

  • 일평균값의 월별 산술평균이며 공식 월평균/월 질량과 다름
  • 삼천포 A/B 농도는 일별 산술평균이며 유량 가중 농도가 아님
  • 여수의 호기 미표기(-) 자료는 대응 근거가 없어 제외
  • 0의 정지/결측 구분 및 측정 유효 플래그가 없음
  • 농도 ppm는 원 제공기관 농도 표기를 근거로 함; 일자료 상세 정의 추가 확인 필요
  • 과거 자료로 사후 재현한 평가이며 해당 월 당시 서비스의 예측 기록이 아닙니다.
  • 입력 자료의 당시 공개·입수 시점은 검증되지 않았습니다.
  • 등록은 파일과 관측·예측의 대응 검사이며 측정 유효성 인증이 아닙니다.
  • 급등·0값·검토 필요 관측을 임의로 삭제하거나 보완하지 않은 계산입니다.
  • 오차는 저장 예측에서 관측을 뺀 값이며, 한 사례의 절대 오차는 RMSE가 아닙니다.
  • 직전 3개월 평균은 이용 가능한 관측의 평균이며 관측 충족 수를 함께 확인해야 합니다.
  • 관측일 충족률은 일자료 존재 비율이며 유효 측정시간·운전시간 충족률이 아닙니다.
  • 특징별 결측 보완·범위 경고는 현재 고정 보고서 계약에서 확인하지 않았습니다.
  • 문서의 일반 기술 근거는 해당 발전소·호기의 실제 고장 원인이나 측정 유효성을 증명하지 않습니다.
  • 참조·형식·수치 검증을 통과해도 자연어의 의미적 근거 충실성은 사용자 검토가 필요합니다.
  • 검색 품질은 소규모 평가이며 전문가가 독립 검증한 결과가 아닙니다.
  • 사용자 승인은 이 보고서 초안의 검토 결정이며 기관 측정 유효성 인증이나 설비 제어 승인이 아닙니다.
