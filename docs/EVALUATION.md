# 모델 구성과 성능 비교

## 비교 대상 구분

여기서 **초기 보완 모델**은 2026년 9월 30일에 원래 자료를 점검하고 ppm 타깃으로 구성한 모델입니다. 공모전 원래 `NOX_kg` 모델과의 같은 단위 비교가 아닙니다. 환산 근거가 확인되지 않은 legacy 결과를 현재 ppm 수치와 비교하지 않습니다.

| 구분 | 구성 | 상태 |
| --- | --- | --- |
| 기본 API | XGBoost·LightGBM 각각 `log1p` 타깃 학습, 검증 가중치 선택 | 2023년 학습, 선택 가중치 XGB 0.00 / LGB 1.00 |
| 이후 기간 재학습 | 같은 계열, 학습을 2025년 상반기까지 확장 | 검증 가중치 XGB 0.04 / LGB 0.96; 자동 교체 없음 |
| 기간별 비교 | A/B/C 각각 모델·전처리·가중치 확정 | 모델 선택의 기간 의존성 확인 |
| 개선 후보 | 기상 및 기상 파생변수 제외, `log1p` LightGBM, 시드 0~4 | ppm으로 역변환한 5개 예측 평균; 미배포 |

기본 학습 설정은 300개 트리, 학습률 0.05, 최대 깊이 3이며 상세 설정은 코드와 저장 메타데이터를 참조합니다. 기본 앙상블은 **로그 예측 공간**에서 가중 결합한 뒤 `expm1`로 복원합니다. 가중치는 XGBoost 비중 0.00~1.00, 간격 0.01로 검증 RMSE를 최소화합니다. 0 또는 1이 선택되면 결과적으로 한 모델만 사용합니다.

결측 중앙값·사용할 열·전처리 통계는 학습 구간에서만 산출합니다. 가중치와 후보는 검증 구간에서 선택하고 후속 평가 전에 고정합니다. 현재 월의 실현된 운전 조건과 이전에 관측한 타깃을 사용하는 **월별 순차 평가**이며, 월초에 미래 6개월을 예측하는 성능을 검증한 것은 아닙니다. 자료의 실제 공표 지연도 별도 확인이 필요합니다.

## 시간 순서 검증

| 반복 | 학습 | 모델·가중치 선정 | 후속 점검 |
| --- | --- | --- | --- |
| A | 2023년 | 2024년 상반기 | 2024년 하반기 |
| B | 2023년~2024년 상반기 | 2024년 하반기 | 2025년 상반기 |
| C | 2023~2024년 | 2025년 상반기 | 2025년 하반기 |

같은 달의 모든 호기를 함께 나눕니다. 2026년 자료는 이 실험의 특징 생성 이전에 제외합니다. 후속 점검 행은 총 382개이고, 학습에 없는 여수 2호기 12개를 분리한 기존 호기 **370개**에서 아래 지표를 계산했습니다. 이 기간은 후속 개선에도 반복해서 확인했으므로 독립 최종 평가로 부르지 않습니다.

| 방법 | RMSE (ppm) | MAE (ppm) |
| --- | ---: | ---: |
| XGBoost | 24.1372 | 6.7338 |
| LightGBM | 23.6028 | 6.7756 |
| 기간별 선정 앙상블 | 23.8109 | 6.8323 |
| 학습 호기 평균 | 25.6692 | 8.9575 |
| 직전 3개월 평균 | 31.1408 | 10.0187 |
| 전월 값 | 34.6672 | 10.0906 |
| 학습 전체 중앙값 | 33.7921 | 13.5035 |
| 개선 후보 | **22.2790** | **6.4795** |

후보는 전월 값 대비 RMSE **35.73%**, MAE **35.79%** 감소, 기존 LightGBM 대비 RMSE **5.61%**, MAE **4.37%** 감소했습니다. 감소율은 `(비교 기준 오차 - 후보 오차) / 비교 기준 오차 × 100`입니다. 전체 오차는 모든 행에서 계산하며, 기간별 RMSE를 단순 평균하지 않습니다.

RMSE는 제곱 오차 평균의 제곱근이라 급등을 크게 놓칠수록 커집니다. MAE는 예측과 실제의 차이를 절댓값으로 평균한 값입니다. MAE 6.48 ppm은 평균 절대 오차가 그 정도라는 뜻이며, 모든 개별 예측이 ±6.48 ppm 이내라는 보장은 아닙니다.

## 지역별: 기존 LightGBM과 개선 후보

| 발전소 | 관측 수 | 기존 RMSE | 후보 RMSE | 기존 MAE | 후보 MAE |
| --- | ---: | ---: | ---: | ---: | ---: |
| 분당 | 136 | 1.22 | 1.16 | 0.86 | 0.83 |
| 삼천포 | 72 | 33.49 | 28.98 | 16.12 | 14.94 |
| 여수 | 18 | 14.13 | **15.90** | 8.91 | 8.76 |
| 영동 | 36 | 58.01 | 57.26 | 26.19 | 25.58 |
| 영흥 | 108 | 1.93 | 1.94 | 1.17 | 1.20 |

단위는 모두 ppm입니다. 분당·영흥 오차가 작아도 영동의 성능은 충분하지 않습니다. 여수는 MAE가 소폭 개선됐지만 RMSE는 악화됐습니다. 발전소별 농도 분포와 관측 수가 달라 전체 수치 하나로 운영 적합성을 판단하기 어렵습니다.

영동·삼천포 대표 급등 구간에서 큰 과소 예측이 확인됐습니다. 개별 월 관측값과 행별 예측은 로컬에서 관리합니다. 유효 급등인지 아직 확인하지 못했으므로 원인을 저감설비 문제로 확정하거나 관측값을 삭제하지 않았습니다.

## 초기 보완 모델과 이후 기간 재학습

2026년 1~8월 중 두 모델 모두 학습에 포함된 기존 호기 **168개 행**을 같은 관측 이력과 입력 조건으로 비교했습니다.

| 모델 | 학습 종료 | RMSE (ppm) | MAE (ppm) |
| --- | --- | ---: | ---: |
| 초기 보완 모델 | 2023년 12월 | 54.7183 | 11.4415 |
| 이후 기간 재학습 | 2025년 6월 | 52.3808 | 10.9089 |
| 감소율 | — | **4.27%** | **4.65%** |

신규 여수 2호기를 포함한 176개 행의 재학습 지표 51.18 / 10.56 ppm은 위 비교와 모집단이 다릅니다. 초기 보완 모델의 2024년 하반기 저장 평가 14.06 / 4.89 ppm 역시 기간이 달라 직접 비교하지 않습니다. 개선 후보 22.28 / 6.48 ppm을 위 2026년 결과와 비교해 향상률을 계산하지 않습니다.

영동 실제 호기 연료를 추가한 별도 비교에서는 2025년 하반기 검증 오차가 감소했지만, 2026년 전체 176개 행에서 RMSE 51.18 → 51.21, MAE 10.56 → 10.62 ppm으로 개선이 이어지지 않았습니다. 자료 품질 보완과 성능 향상은 별개로 확인했습니다.

## 후보 선정과 한계

120개 실험은 4개 후보·2개 기상 품질 입력 정책·3개 기간·5개 시드의 조합입니다. 실제 모델 적합은 앙상블의 두 모델을 포함해 150회입니다. 후보 선정은 검증 구간의 시드 평균 예측에서 MAE, RMSE 순으로 진행하며 전체·발전소별 악화 제한을 적용했습니다. 선정 기록에는 `not_deployed: true`, `independent_final_evaluation: false`가 명시돼 있습니다.

남은 작업은 기관 일평균 재현, 같은 규칙의 전체 타깃 재구성, 유효 급등에 대한 연소·SCR 자료 보강, 새 미사용 기간 평가입니다. 운전·기상 입력의 실제 입수 시점도 확인해야 실사용 예측 범위를 정의할 수 있습니다.
