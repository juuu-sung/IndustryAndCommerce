# 로컬 평가·검증 결과

**이 디렉터리의 실제 결과 파일은 Git에서 제외합니다.** 집계 표와 그림만 `docs/generated/`에 공개했습니다. 원래 평가 결과는 로컬 연결 스크립트로 복원할 수 있습니다.

저장된 지표의 의미와 비교 조건은 [모델 평가 문서](../../docs/EVALUATION.md)에 정리했습니다.

| 결과 묶음 | 내용 |
| --- | --- |
| `retraining/` | 2026년 동일 기존 호기 168개 행에서 초기 보완/이후 재학습 비교 |
| `unit_fuel_retraining/` | 영동 실제 호기 연료 입력 전후 비교 |
| `temporal_validation_20261001/` | A/B/C, 전체 382개 행·기존 호기 370개 행·신규 호기 12개 행 |
| `operations_validation_20261002/` | 시간별 발전 패턴의 추가 효과·품질·API 실험 |
| `pre_request_experiments_20261002/` | 오차 분석·변수 묶음·로그/ppm 비교 |
| `readiness_20261002/` | 기상·운전 자료 보완, 후보 프로토콜·시드별/평균 예측·선정 결과 |
| `target_validation_20261003/` | 기관 요청 템플릿·연구 타깃 v0·저장 결과의 동일 관측 재비교 |

`COMPLETE` 표시는 해당 과거 개발 실험이 완료됐다는 뜻입니다. 기관 타깃 확인이나 새 미사용 기간 평가까지 완료했다는 뜻은 아닙니다. 날짜별 JSON의 개인 작업 경로는 과거 출처 기록입니다.

대량 후보 모델 파일은 포함하지 않습니다. `selection_lock.json`에는 당시 생성한 전체 모델의 해시가 남아 있지만 일부 모델 경로는 이 저장소에 없습니다. 새 출력 디렉터리로 후보 실험을 재실행하면 해당 모델을 생성할 수 있습니다. 기준·시간 검증·운전 실험 모델도 공개하지 않으며 로컬에서 연결합니다.

신규 출력은 `local_*`, `new_*`, `verified_*`처럼 Git에서 제외한 폴더에 기록합니다. 공개할 새 결과는 먼저 출처·비공개 정보·타깃 정의를 검토한 후 별도 선별합니다.
