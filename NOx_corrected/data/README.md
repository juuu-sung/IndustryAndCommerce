# 로컬 데이터 연결

**데이터 파일은 공개 저장소에 포함하지 않습니다.** `scripts/restore_local_assets.py`로 기존 작업 폴더에서 로컬 파일을 연결할 수 있습니다.

실행 기준 경로는 `NOx_corrected/`입니다. 스냅샷은 실험 당시 파일을 보존하므로 서로 같은 공개 원본을 공유하는 디렉터리가 있습니다. Git은 동일 내용의 파일 객체를 중복 저장하지 않습니다.

| 디렉터리 | 역할 |
| --- | --- |
| `raw/` | 2023~2024년 초기 원본과 진단용 legacy 자료 |
| `retrieved/20261001/` | 이후 공개 다운로드 원문·원본 중첩 대조·요청 기록 |
| `extended_20261001/` | 2026년 8월까지 통합한 재학습 자료 |
| `unit_fuel_20261001/` | 영동 실제 호기 연료를 명시적으로 추가 |
| `operations_20261002/` | 품질·월 실적 대조를 통과한 발전 패턴 특징 |
| `readiness_bundle_20261002/` | 기상 출처·충족률, 2026년 영동 운전 자료 보완 |
| `runtime/` | 로컬에서 초기화하는 SQLite, Git 제외 |
| `provider_private/` | 향후 기관 확인 원문·비공개 자료, Git 제외 |

CSV 단위와 타깃 구성은 [데이터 품질 설명](../../docs/DATA_QUALITY.md)을 따릅니다. 연료·기상·운전 메타데이터는 실제 관측과 파생·추정값을 구분합니다. `manifest.json`의 `files` SHA-256은 해당 자료 묶음의 파일과 대조할 수 있습니다. 수집 시각과 URL, 공급기관 대응 관련 제약은 각 manifest에 보존했습니다.

로컬 기관 요청 템플릿 `reports/target_validation_20261003/request_bundle`은 아직 확인되지 않은 상태를 표시합니다. 템플릿은 실제 기관 회신 자료가 아닙니다. 개인정보·API 키·기관 비공개 자료를 이 공개 폴더에 추가하지 마세요.
